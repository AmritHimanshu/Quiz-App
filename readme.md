# ⚡ MTS Quiz App

A dynamic and interactive quiz application built with **Next.js 14**, **Tailwind CSS**, **Framer Motion**, and **Canvas Confetti**. Users can play quizzes, view results with winning animations, and climb the leaderboard—all in a sleek, futuristic UI.

---

## 🚀 Features

- 🎮 **Quiz Launch with Countdown** animation  
- 🎉 **Winning Celebration** with confetti  
- 📊 **Real-Time Result Dashboard** (Score, Coins, Accuracy, etc.)  
- 🧠 Multiple Quizzes with varying difficulty levels  
- 🏆 **Leaderboard** Navigation  
- 🔥 Clean, animated UI using **Framer Motion**  
- 🌈 Custom themes: neon green, cyber purple, glow effects
